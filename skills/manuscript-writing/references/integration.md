# 全文整合与一致性检查

整合是核对不同部分是否共同支撑同一条研究论证，不是把所有草稿机械拼接。

## 核对顺序

1. **主线**：标题、摘要、引言末段、方法、结果和讨论是否指向同一研究问题与贡献。
2. **术语**：任务名称、疾病名称、队列、类别、模型模块、方向定义、指标缩写和补充材料名称是否统一。列出不一致位置后再做最小范围修改。
3. **事实**：样本量、数据来源、纳排条件、数据划分、参数选择范围、基线名称、指标数值和小数位是否一致。以当前作者确认的数据源为准；不因为整合要求而重新审计全部实验。
4. **证据链**：每项关键主张能否追溯到结果、表图或文献；每项主要结果是否回答预先提出的问题；推断是否越过证据边界。
5. **图表**：正文是否按顺序提及图表，数值、组名、面板字母和图注是否一致；图表是否提供正文没有的必要信息，是否和正文重复。
6. **正文与补充材料**：正文保留理解研究问题、方法公平性和主要发现所需信息；补充材料承载复现所需的详细流程、额外结果或扩展表格。遵从作者的 Supplementary Data / Information 命名习惯，不自行引入另一套缩写。
7. **摘要与结论**：只保留正文确有证据支持的主要结果；摘要不塞入不必要的实验流程，讨论不把结果改写成更强的因果主张。
8. **引用**：文内每个引用能支持其所在句子，文末条目与文内引用对应，书目信息按目标格式核对。

## 问题分级

- **阻断性**：会改变科学含义、结果解释或可复现性，例如类别定义冲突、数据泄漏疑点、数值互相矛盾。
- **重要但可修**：逻辑缺环、主张缺少直接证据、图表表达与正文不符。
- **编辑性**：术语、语序、格式和重复表述。

先处理阻断性问题，再处理重要问题，最后统一语言和格式。发现问题时给出定位、证据、影响和建议，不默默替作者改动科学含义。排版只在明确要求时执行。
