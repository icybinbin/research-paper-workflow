# 领域文献与写作分析

有目标地检索、阅读、整理和回读文献，让研究判断与写作规划有具体依据。阅读不会永久训练模型，阅读成果应保存为项目文件。

## 按任务选择阅读模式

- **研究现状**：比较方法、贡献、证据和不足，为研究定位提供依据。
- **写作分析**：分析章节和段落任务、句子衔接、实验细节取舍，为写作提供范例。
- **图形分析**：分析框架图的信息层级、结构呈现、布局与视觉编码，为绘图提供设计依据。

只加载当前模式需要的材料。具体操作与记录模板见 [阅读协议](references/reading-workflow.md)。

## 检索与阅读

1. 明确研究问题、关键词、目标论文类型与时间范围。作者未指定时，近期检索优先覆盖过去三年，同时保留必要的经典与直接相关工作；旧综述或同方向经典不能因年份被机械排除。
2. 先做代表性筛选，再深入阅读最相关的少数论文。数量是工作量估计，不是证明掌握领域的标准；用户指定数量时尽力满足并报告可获取程度。
3. 使用可用的检索工具或作者提供的材料，优先原始论文与正式出版信息。实际打开相关原文，不将搜索标题、片段或摘要当作全文阅读。
4. 记录访问层级：全文、相关章节、摘要或仅元数据。只能看到摘要时，不推断详细结构、实现或作者未说明的局限。
5. 将原文陈述、AI分析和对当前研究的建议分开。研究现状包含接近、不同和相反的证据，不通过选择性检索伪造研究缺口。
6. 学习信息组织，不照搬句子、图形或固定章节。避免把目标期刊的个别文章风格当作领域通则。

## 保存与再次调用

在作者指定目录或 `manuscript-workspace/` 中保存 `literature-map.md`，以及需要时的 `reading-notes/`、`writing-exemplars.md` 或 `figure-exemplars.md`。笔记包含可靠出处、原文定位、阅读层级、关键判断和用途，保存短引文时遵守来源版权限制。

更新 `project.md` 的文献入口。写作或绘图前读取相关笔记；重要事实、模型局限和精确引用必要时回到原文核实。笔记足够且来源未变时，不重复检索全部文献。

## 完成标准

说明代表路线的区别、最相关工作的关系、待解决问题，以及哪些观察会改变当前规划。不能以“已学习这些论文”替代具体理解。工具或原文不可获取时标明缺口，处理已有材料，不伪造阅读经历。
