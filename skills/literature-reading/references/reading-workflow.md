# 阅读协议

## 分层读取

先明确要作出的决定，例如研究定位、引言段落安排、方法正文详略或框架图构图。检索词包含任务、数据类型、方法家族或期刊范围；记录检索日期与实际年份区间。

近期范围默认过去三年，是优先筛选范围，不是排除标准。需要时补经典工作、直接近邻、已公开但发布时间较新的工作。不能只挑支持预设故事的文章。

广读用来识别路线，精读用来支持具体判断。深读相关引言、方法、结果、讨论或图，不要求每个任务精读每篇全文。已有笔记足够时复用。

## 每篇的最小记录

```markdown
# 文献阅读记录

题名、作者、年份、期刊：
DOI或稳定链接：
本地原文或网页入口：
实际阅读范围：全文／指定章节／摘要／元数据
读取日期：

## 原文事实

研究问题、方法、主要结果、作者明确说明的局限。
每条重要判断给出章节、页码、图号或短原文定位。

## 分析

AI提取的方法关系与不足，并说明推断依据。

## 对当前项目的作用

研究现状／最近比较／写作参考／图形参考。

## 需要回读的位置

事实、细节或引用尚未确认的部分。
```

## 研究现状模式

把方法按共同思路分组，再突出少量代表工作。逐篇区分：建模对象、信息来源、如何整合、评价任务、关键证据。描述局限时检查它是否对整个方法家族都成立，避免以部分方法代替所有方法。

接近本文的工作应进入理解和定位记录。正式稿不需要引用检索到的每篇论文，但省略不能导致虚假的“没有人做过”或错误描述。

## 写作分析模式

分析实际段落而不是只给摘要。记录：

- 每段承担什么任务，怎样承接上下文。
- 段内句子如何推进，哪些工作点名详写，哪些分组略写。
- 从已有贡献到不足的转折怎样得到前文支持。
- 方法怎样定义变量、介绍结构、安排实现细节。
- 结果怎样组织比较、消融和其他对照。
- 讨论怎样解释发现，与引言和结果有何分工。

需要字数、段数或引用数时直接依据原文统计，说明计数范围，不能凭印象估计为精确值。输出可复用的写作建议，不套用原文论点或复制句子。

## 图形分析模式

实际查看图像或PDF对应页。记录主视觉、图形层级、输入输出、网络结构可读性、分支排列、颜色用途、重复压缩方式和图注分工。

每个拟采用的特点说明适用理由。不以“顶刊配色”“高级风格”代替具体分析。不复制其他论文特有的视觉资产，采用一般组织原则并自行绘制。

## 长任务与交接

保存 `literature-map.md` 作为短索引，详细记录放到 `reading-notes/`。按需要另存 `writing-exemplars.md`、`figure-exemplars.md`。后续窗口先读取当前任务对应的索引条目和笔记，精确事实再回原文。

压缩对话不能替代有出处的阅读记录。项目材料与未公开内容留在项目目录，不将全文或私有材料复制进公开 skill 包。
